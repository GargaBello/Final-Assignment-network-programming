# Final-Assignment-network-programming

Sebastian Saastamoinen - 5SD808

Controls - 
    W - Move up
    S - Move down
    A - Move left
    D - Move right
    V - Place bomb

Bombs explode 6 seconds after placement. Bombs kill both the player who placed them and the other players. The player is reconciled when they move 2 tiles from the server position. 


The game begins rougly 15 - 30 sec after 3 players have joined. When every player except one dies the game transitions to a post game and disconnect all the players.
